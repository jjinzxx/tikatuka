# TikaTuka (티카투카)

[티카투카 온라인](http://xn--ob7ba96zmwa.xn--oi2b61z32a.xn--3e0b707e/)
<br><br>
Cult of the Lamb의 미니게임 Knucklebones를 모티브로 제작한 웹 기반 주사위 대전 게임입니다. 순수 HTML/CSS/JavaScript 단일 파일로 동작하며, 싱글 플레이(vs AI)와 입장코드 기반 2인 온라인 대전을 모두 지원합니다.

## 개요

두 플레이어가 각자 3열의 보드에 주사위를 굴려 배치하며 점수를 겨루는 게임입니다. 원작 룰을 그대로 구현한 클래식 모드와, 실드 주사위와 주사위 맞교환(알까기) 메커니즘을 추가한 자체 변형 룰인 실드 모드 두 가지를 제공합니다.

## 주요 기능

- 클래식 룰과 실드 룰 중 선택 가능한 게임 모드
- 싱글 플레이: 휴리스틱 기반 AI(Enemy)와 대전
- 2인 온라인 대전: 4자리 입장코드로 방을 만들고 참가
- 포인트(TP) 베팅 시스템: 승리 시 500 TP 획득, 패배 시 500 TP 차감
- 리롤, 재대결, 전적 기록 등 부가 기능
- 반응형 레이아웃으로 데스크톱과 모바일 모두 지원

## 게임 규칙

### 클래식 룰

Knucklebones 원작 방식을 그대로 따릅니다.

- 각 플레이어는 3개의 줄을 가지며, 한 줄에는 주사위를 최대 3개까지 놓을 수 있습니다.
- 줄 점수는 같은 눈의 개수에 따라 제곱으로 증가합니다. (눈 × 개수의 제곱)
  - 예: 4가 2개면 4 × 2² = 16점, 4가 3개면 4 × 3² = 36점
- 내가 놓은 주사위와 같은 눈이 상대의 같은 줄에 있으면, 해당 주사위는 배치 즉시 자동으로 제거됩니다.
- 어느 한쪽의 보드가 가득 차면 게임이 종료되며, 총점이 높은 쪽이 승리합니다.

### 실드 룰

클래식 룰에 다음 메커니즘을 추가한 자체 변형 규칙입니다.

- 줄 점수는 주사위 눈의 합계에 같은 눈 보너스(눈 × (개수 − 1))를 더해 계산합니다.
  - 예: 4가 2개면 (4+4) + 4 = 12점, 4가 3개면 (4+4+4) + (4×2) = 20점
- 3개의 줄 중 2줄 이상에서 점수가 높은 쪽이 승리합니다. 줄 승수가 동률이면 총점이 높은 쪽이 승리합니다.
- 주사위는 일반 주사위와 실드 주사위 두 종류로 구분됩니다.
  - 일반 주사위는 자신의 보드에만 놓을 수 있습니다.
  - 실드 주사위는 자신과 상대의 보드 어느 쪽에나 놓을 수 있으며, 아래의 맞교환으로 제거되지 않습니다.
- 게임의 첫 주사위는 항상 실드 주사위이며, 자신의 보드에만 놓을 수 있습니다.
- 굴린 일반 주사위와 같은 눈의 일반 주사위가 상대의 같은 줄에 있는 경우, 해당 줄에 놓으면 선택의 여지 없이 맞교환이 발생합니다. 내 주사위는 보드에 놓이지 않고 소모되며, 상대의 같은 눈 일반 주사위는 모두 함께 제거됩니다.
- 맞교환이 발생하면 보상으로 실드 주사위 1개를 즉시 굴려 배치합니다.
- 각 플레이어는 게임당 1회의 리롤권을 가지며, 리롤 시 기존 눈과 새로 굴린 눈 중 하나를 선택해 배치합니다.
- 보드가 가득 찬 플레이어의 턴은 자동으로 건너뜁니다. 양쪽 보드가 모두 가득 차면 게임이 종료됩니다.

## 온라인 대전 구조

별도의 게임 서버 없이 Supabase Realtime의 브로드캐스트 및 프레즌스 채널을 통신 계층으로 사용합니다.

- 방장이 방을 만들면 클라이언트에서 임의의 4자리 코드가 생성되고, `tikatuka:{코드}` 이름의 Realtime 채널을 구독합니다.
- 게스트는 코드를 입력해 같은 채널을 구독하며, 프레즌스 상태를 통해 방장의 존재와 이미 다른 게스트가 있는지를 확인합니다.
- 게임 룰(클래식/실드)은 방장의 설정이 프레즌스 정보를 통해 게스트에게 전달되어 적용됩니다.
- 게임 중 발생하는 주사위 굴림, 배치, 맞교환, 턴 종료, 재대결 요청 등의 이벤트만 메시지로 주고받으며, 각 클라이언트는 수신한 이벤트를 바탕으로 자신의 화면에서 상태를 재구성합니다.
- 서버 측에 게임 상태나 방 정보가 영구 저장되지 않으며, 채널은 게임 종료 또는 접속 종료 시 정리됩니다.
- 사용하는 API 키는 클라이언트에 노출되어도 안전한 publishable(anon) 키이며, 데이터베이스 테이블에는 어떠한 읽기 및 쓰기도 발생하지 않습니다.

싱글 플레이는 이 통신 계층을 사용하지 않고 클라이언트 내에서 동일한 게임 로직을 AI와 함께 실행합니다.

## 기술 스택

- HTML, CSS, Vanilla JavaScript (프레임워크 없이 단일 파일로 구성)
- Supabase JS Client v2 (Realtime Broadcast, Presence)
- Google Fonts (Jua, Gowun Dodum)

## 파일 구조

```
tikatuka_multi.html   싱글/멀티 통합 버전 (실행 파일 1개)
```

모든 마크업, 스타일, 로직이 하나의 HTML 파일에 포함되어 있어 별도의 빌드 과정 없이 브라우저에서 바로 실행할 수 있습니다.

## 실행 방법

1. `tikatuka_multi.html` 파일을 다운로드합니다.
2. 브라우저에서 파일을 엽니다.
3. 닉네임과 게임 룰을 선택한 뒤, 싱글 플레이 또는 방 만들기/입장하기 중 하나를 선택해 시작합니다.

온라인 대전을 위해서는 인터넷 연결이 필요하며, 별도의 서버 설치나 로그인 절차는 없습니다.

## 향후 개선 방향

- 클라이언트에서 생성하는 주사위 눈을 서버 권위 구조(Edge Function)로 전환해 조작 가능성을 제거
- 룰별 전용 Supabase 프로젝트 분리를 통한 리소스 격리
- 관전 모드 및 리플레이 기능 추가
