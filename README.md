# TikaTuka (티카투카)

[티카투카 온라인](http://xn--ob7ba96zmwa.xn--oi2b61z32a.xn--3e0b707e/)
<br><br>
Cult of the Lamb의 미니게임 Knucklebones를 모티브로 제작한 웹 기반 주사위 대전 게임입니다. 순수 HTML/CSS/JavaScript 단일 파일로 동작하며, 싱글 플레이(vs AI)와 입장코드 기반 2인 온라인 대전을 모두 지원합니다.

## 개요

두 플레이어가 각자 3열의 보드에 주사위를 굴려 배치하며 점수를 겨루는 게임입니다. 원작 룰을 그대로 구현한 클래식 모드와, 실드 주사위·주사위 맞교환(알까기)·타짜의 손놀림 등의 메커니즘을 추가한 자체 변형 룰인 로아룰 두 가지를 제공합니다.

## 주요 기능

- 클래식 룰과 로아룰 중 선택 가능한 게임 모드
- 싱글 플레이: 휴리스틱 기반 AI(상대)와 대전
- 2인 온라인 대전: 4자리 입장코드로 방을 만들고 참가
- 3인 이상 접속 시 자동 관전 모드 전환, 활성 플레이어 이탈 시 대기 중인 관전자가 이어서 참가
- 관전 모드에서 양쪽 보드 전체(주사위 배치·줄 점수·현재 턴)를 실시간으로 미러링
- 방 단위 실시간 채팅: 플레이어와 관전자 모두 참여 가능 (관전자 메시지에는 👁 표시)
- 포인트(TP) 베팅 시스템: 승리 시 500 TP 획득, 패배 시 500 TP 차감 (기본 보유 0 TP)
- 멀티플레이 전적을 반영하는 티어(랭크) 시스템 — 브론즈부터 마스터까지
- 매판 시작 전 주사위 굴리기로 선공 결정, 타짜의 손놀림(리롤), 홀드, 재대결 등 부가 기능
- 반응형 레이아웃으로 데스크톱과 모바일 모두 지원

## 게임 규칙

### 클래식 룰

Knucklebones 원작 방식을 그대로 따릅니다.

- 각 플레이어는 3개의 줄을 가지며, 한 줄에는 주사위를 최대 3개까지 놓을 수 있습니다.
- 줄 점수는 같은 눈의 개수에 따라 제곱으로 증가합니다. (눈 × 개수의 제곱)
  - 예: 4가 2개면 4 × 2² = 16점, 4가 3개면 4 × 3² = 36점
- 내가 놓은 주사위와 같은 눈이 상대의 같은 줄에 있으면, 해당 주사위는 배치 즉시 자동으로 제거됩니다.
- 어느 한쪽의 보드가 가득 차면 게임이 종료되며, 총점이 높은 쪽이 승리합니다.

### 로아룰

클래식 룰에 다음 메커니즘을 추가한 자체 변형 규칙입니다.

- 줄 점수는 주사위 눈의 합계에 같은 눈 보너스(눈 × (개수 − 1))를 더해 계산합니다.
  - 예: 4가 2개면 (4+4) + 4 = 12점, 4가 3개면 (4+4+4) + (4×2) = 20점
- 3개의 줄 중 2줄 이상에서 점수가 높은 쪽이 승리합니다. 줄 승수가 동률이면 총점이 높은 쪽이 승리합니다.
- 주사위는 일반 주사위와 실드 주사위 두 종류로 구분됩니다.
  - 일반 주사위는 자신의 보드에만 놓을 수 있습니다.
  - 실드 주사위는 자신과 상대의 보드 어느 쪽에나 놓을 수 있으며, 아래의 맞교환으로 제거되지 않습니다.
- 게임의 첫 주사위는 항상 실드 주사위이며, 자신의 보드에만 놓을 수 있습니다.
- 굴린 일반 주사위와 같은 눈의 일반 주사위가 상대의 같은 줄에 있는 경우, 해당 줄에 놓으면 선택의 여지 없이 맞교환이 발생합니다. 내 주사위는 보드에 놓이지 않고 소모되며, 상대의 같은 눈 일반 주사위는 모두 함께 제거됩니다.
- 맞교환이 발생하면 보상으로 실드 주사위 1개를 즉시 굴려 배치합니다.
- 각 플레이어는 게임당 1회의 타짜의 손놀림(리롤)을 가지며, 사용 시 기존 눈과 새로 굴린 눈 중 하나를 선택해 배치합니다.
- 보드가 가득 찼거나 홀드한 플레이어의 턴은 자동으로 건너뜁니다. 양쪽 모두 더 이상 둘 수 없는 상태(꽉 찼거나 홀드)가 되면 게임이 종료됩니다.

### 공통 규칙

- **선공 결정**: 매판 시작 전(재대결 포함) 양쪽이 동시에 주사위를 굴려 더 높은 눈이 나온 쪽이 선공이 됩니다. 동점이면 자동으로 다시 굴립니다.
- **홀드**: 버튼을 누르면 그 순간부터 이번 판이 끝날 때까지 자신의 턴이 계속 자동으로 넘어갑니다. 한 번 누르면 되돌릴 수 없습니다.

## 온라인 대전 구조

별도의 게임 서버 없이 Supabase Realtime의 브로드캐스트 및 프레즌스 채널을 통신 계층으로 사용합니다.

- 방장이 방을 만들면 클라이언트에서 임의의 4자리 코드가 생성되고, `tikatuka:{코드}` 이름의 Realtime 채널을 구독합니다.
- 게스트는 코드를 입력해 같은 채널을 구독하며, 프레즌스 상태를 통해 방장의 존재와 이미 다른 게스트가 있는지를 확인합니다. 역할(호스트/게스트/관전자)은 프레즌스 상태를 먼저 관찰한 뒤에만 확정·기록해 동시 입장 시의 역할 충돌을 방지합니다.
- 게임 룰(클래식/로아룰)은 방장의 설정이 프레즌스 정보를 통해 게스트에게 전달되어 적용됩니다.
- 게임 중 발생하는 주사위 굴림, 배치, 맞교환, 홀드, 턴 종료, 재대결 요청 등의 이벤트만 메시지로 주고받으며, 각 클라이언트는 수신한 이벤트를 바탕으로 자신의 화면에서 상태를 재구성합니다.
- 이미 두 명이 대결 중인 방에 추가로 입장하면 자동으로 **관전 모드**가 됩니다. 관전자는 호스트가 보내주는 상태 스냅샷을 받은 뒤 이후의 게임 이벤트를 반영해, 양쪽 보드 전체와 줄 점수·현재 턴을 실시간으로 확인할 수 있습니다. 매판 시작(재대결 포함) 시 호스트가 관전자 전원에게 새 스냅샷을 보내 미러 상태를 다시 맞춥니다.
- 채팅은 게임 이벤트와 분리된 별도의 브로드캐스트 이벤트로 주고받으며, 같은 방의 플레이어와 관전자 모두 사용할 수 있습니다. 채팅 내역은 어디에도 저장되지 않습니다.
- 활성 플레이어 중 한 명이 이탈하면, 남은 플레이어가 대기 중인 관전자 한 명에게 그 시점의 보드·턴·타짜의 손놀림 사용 여부·홀드 상태까지 포함한 전체 스냅샷을 전달해 좌석을 이어받게 합니다. 대체할 관전자가 없으면 대결이 종료됩니다.
- 나와 무관한 사람(다른 관전자 등)의 접속 종료는 무시하도록 처리되어 있어, 제3자가 들어오거나 나가도 기존 대결에 영향을 주지 않습니다.
- 서버 측에 게임 상태나 방 정보가 영구 저장되지 않으며, 채널은 게임 종료 또는 접속 종료 시 정리됩니다.
- 사용하는 API 키는 클라이언트에 노출되어도 안전한 publishable(anon) 키이며, 데이터베이스 테이블에는 어떠한 읽기 및 쓰기도 발생하지 않습니다.

싱글 플레이는 이 통신 계층을 사용하지 않고 클라이언트 내에서 동일한 게임 로직을 AI와 함께 실행합니다.

## 티어(랭크) 시스템

**2인 온라인 대전 결과에만** 반영되는 별도의 랭크 시스템입니다. 싱글 플레이는 전적에만 기록되고 티어에는 영향을 주지 않습니다.

- 브론즈 → 실버 → 골드 → 플래티넘 → 다이아(각 티어 5단계) → 마스터
- 승리 시 +1별, 패배 시 -1별. 별이 0이어도 하위 등급으로 강등되지 않습니다.
- 3연승부터 +2별, 5연승부터 +3별의 가산 보너스가 적용됩니다.
- 나보다 티어가 높은 상대에게 패배하면 별이 깎이지 않는 보호 규칙이 있습니다.
- 다이아 최고 단계에서 승급하면 마스터로 전환되며, 100점에서 시작해 승리 시 +10~15점, 패배 시 -10점을 얻습니다. 마스터는 점수가 마이너스가 되어도 강등되지 않습니다.
- 상대의 티어는 같은 방에 입장한 시점부터 프레즌스 정보로 공유되어 화면에 표시됩니다.
- 서버 DB가 아닌 **브라우저 localStorage**에만 저장되는 개인 기록입니다. 기기나 브라우저를 바꾸면 초기화되며, 별도의 로그인 절차나 서버 검증은 없습니다.

## 기술 스택

- HTML, CSS, Vanilla JavaScript (프레임워크 없이 단일 파일로 구성)
- Supabase JS Client v2 (Realtime Broadcast, Presence)
- 브라우저 localStorage (티어 기록 저장)
- Google Fonts (Jua, Gowun Dodum)

## 파일 구조

```
index.html   싱글/멀티 통합 버전 (실행 파일 1개, GitHub Pages 루트에 배포)
```

모든 마크업, 스타일, 로직이 하나의 HTML 파일에 포함되어 있어 별도의 빌드 과정 없이 브라우저에서 바로 실행할 수 있습니다.

## 실행 방법

1. `index.html` 파일을 다운로드하거나 위 링크로 바로 접속합니다.
2. 닉네임과 게임 룰을 선택한 뒤, 싱글 플레이 또는 방 만들기/입장하기 중 하나를 선택해 시작합니다.
3. 이미 대결이 진행 중인 방에 입장하면 자동으로 관전 모드가 됩니다.

온라인 대전을 위해서는 인터넷 연결이 필요하며, 별도의 서버 설치나 로그인 절차는 없습니다.

## 향후 개선 방향

- 클라이언트에서 생성하는 주사위 눈을 서버 권위 구조(Edge Function)로 전환해 조작 가능성을 제거
- 룰별 전용 Supabase 프로젝트 분리를 통한 리소스 격리
- 티어 시스템을 서버 기반(로그인 + DB)으로 전환해 기기 간 동기화 및 조작 방지 지원
- 다수의 관전자가 대기 중일 때의 대기열 순서 관리
